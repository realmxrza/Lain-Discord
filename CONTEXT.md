# Lain Desktop Pet Context

This context names the domain concepts shared by the Lain desktop pet across the Vencord plugin and standalone browser snippet.

## Language

**LainPet**:
The animated desktop pet that responds to commands, user input, and ambient behavior while moving through the viewport.
_Avoid_: avatar, character

**Movement**:
LainPet's change of position through the viewport, whether commanded or autonomous.
_Avoid_: animation, navigation

**Interaction**:
A deliberate action involving LainPet, including movement commands, dragging, speech, expression, and outfit changes.
_Avoid_: event (when referring to any interaction)

**Ambient behavior**:
Spontaneous activity that occurs while LainPet is running, such as speech, expressions, and outfit changes.
_Avoid_: background task

**Speech**:
A dialogue line shown in the bubble above LainPet, either a random line or one supplied by the caller.
_Avoid_: message, chat

**Expression**:
A temporary reaction sprite shown above LainPet.
_Avoid_: emote, emoji
