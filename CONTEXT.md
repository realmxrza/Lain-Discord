# Lain Desktop Pet Context

This context names the domain concepts shared by the Lain desktop pet across the Vencord plugin and standalone browser snippet.

## Language

**LainPet**:
The animated desktop pet that responds to commands, user input, and ambient behavior while moving through the viewport.
_Avoid_: avatar, character

**Movement**:
LainPet's change of position through the viewport, whether commanded, autonomous, event-driven, or caused by sugar rush.
_Avoid_: animation, navigation

**Interaction**:
A deliberate action involving LainPet, including movement commands, dragging, speech, expression, outfit changes, special events, and sugar rush.
_Avoid_: event (when referring to any interaction)

**Ambient behavior**:
Spontaneous activity that occurs while LainPet is running, such as speech, expressions, outfit changes, special events, Navi drops, and flying miscellany.
_Avoid_: background task

**Navi**:
A collectible falling object that LainPet can approach and collect.
_Avoid_: item, pickup

**Flying miscellany**:
Transient flying objects that cross the viewport independently of LainPet.
_Avoid_: decoration, particle

**Sugar rush**:
A temporary movement state in which LainPet moves rapidly and bounces within the viewport.
_Avoid_: boost, dash

**Special event**:
A temporary outfit-specific interaction that changes LainPet's visible presentation and movement behavior.
_Avoid_: animation, effect
